# Exercise 4.1 — SVG House and Garden

This project is part of **COS30045 Data Visualisation, Exercise 4.1**. The webpage illustrates a house on a hill with a garden and a winding stone pathway using SVG shapes in HTML.

## Declaration of AI Use

I used **OpenAI ChatGPT** as a coding and design assistant while developing this exercise.

ChatGPT assisted with:
- Generating the initial HTML and SVG code for the house, hill, garden, trees, flowers, and other scenery.
- Using SVG primitives such as `<rect>`, `<circle>`, `<ellipse>`, `<polygon>`, `<line>`, `<path>`, and `<text>`.
- Grouping the two windows with `<g>` and positioning them using `transform="translate(...)"`.
- Revising the layout and layering of the roof and window elements in response to my feedback.
- Designing and refining the winding stone pathway, including its perspective, individual stones, and connection to the front steps.

I provided the design requirements, reviewed the output, requested changes, and worked through iterative refinements with ChatGPT. The resulting code was based on that collaboration rather than written entirely without AI assistance.

## Learning Focus

This exercise demonstrates SVG coordinates, styling, grouping, transforms, drawing order, and the use of the browser's DOM inspector. All illustration elements are drawn with SVG markup rather than embedded raster artwork.
